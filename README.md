# Kikay Repuestos - Web Frontend

Un proyecto web estático creado para una empresa de importación de repuestos automotrices y maquinaria pesada. El objetivo de este proyecto es demostrar una maquetación limpia utilizando estructura semántica y estilos modulares sin depender de frameworks externos.

##  Tecnologías utilizadas

* **HTML5:** Marcado semántico para mejorar la accesibilidad y el SEO.
* **CSS3:** Estilos en "Vanilla CSS", utilizando Flexbox para el posicionamiento y la adaptabilidad.

##  Características principales

* **Código modular:** El proyecto está dividido en tres vistas principales, cada una vinculada únicamente a su propia hoja de estilos para evitar conflictos y sobrecarga de código.
* **Componentes reutilizables:** El encabezado (*header*) y el pie de página (*footer*) mantienen un diseño consistente a lo largo de toda la navegación.
* **Maquetación sin frameworks:** Todo el diseño, desde la grilla de productos hasta el formulario de contacto, fue construido desde cero.

##  Estructura del proyecto

El repositorio contiene los siguientes archivos principales:

* `index.html` / `index.css`: Página de inicio (Landing/Hero).
* `catalogo.html` / `catalogo.css`: Sección de productos con diseño en cuadrícula (Grid/Flexbox).
* `contacto.html` / `contacto.css`: Formulario de cotización y datos de ubicación de la empresa.
